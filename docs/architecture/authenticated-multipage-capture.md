# 多页与登录态采集安全设计（P2，未实现）

本文只定义后续实现边界，不代表当前产品已经支持多页、登录态、Cookie、令牌或凭据采集。当前 URL 导入仍只访问用户明确提交的单个公开页面。

## 风险与原则

登录态浏览会把第三方账号权限带入采集器，主要风险是凭据泄露、越权访问、恶意页面跨域跳转、会话残留、私密内容进入模型上下文，以及工具日志意外保存敏感参数。设计顺序必须是最小权限、可见授权、隔离、可撤销、可审计，最后才是覆盖率。

## 必须满足的授权流程

1. 用户新建一次性采集会话，明确填写允许访问的起始域名、页面范围和最大页数；默认只允许同源。
2. 系统在隔离浏览器中打开页面，由用户本人完成登录。ProtoAlign 不接收、代理或保存账号密码、验证码、API Token。
3. 登录后再次展示将采集的域名、路径与数据类型，用户确认后才开始；重定向到未授权域名时暂停并重新授权。
4. 用户可以随时停止；达到页数、时长、域名或错误阈值时自动停止，不后台继续运行。

## 隔离与数据处理

- 每次任务使用独立浏览器上下文和临时目录，不复用个人浏览器配置；任务结束或失败后销毁上下文、Cookie、缓存、IndexedDB 和临时文件。
- 网络层只允许已授权域名及页面运行所需的静态资源；下载、文件上传、弹窗、外部协议、浏览器扩展和服务端代码执行默认禁止。
- Cookie、Authorization Header、表单值、密码字段和存储令牌不得进入应用数据库、Agent 提示词、工具结果、错误响应、截图文件名或日志。
- 送入 Agent 的仍是经过字段过滤的 DOM、可见文字、控件与稳定位置；密码框值、隐藏字段和敏感属性必须在采集器内删除。
- 截图与 DOM 产物沿用项目级隔离和删除策略，并明确标注来源会话、授权范围与采集时间。

## 审计与停止条件

审计记录只保存：操作者、开始/结束时间、授权域名与路径、访问页面清单、状态码摘要、过滤项计数、停止原因和产物 ID。不得保存 Cookie、请求头或表单内容。

以下任一情况立即停止并如实报错：跳转到未授权域名；出现验证码、设备确认或反自动化挑战；请求下载或上传文件；检测到权限提升；会话超时；连续三页为空壳；用户撤销授权；隔离或敏感字段过滤失败。失败不得回退为公开匿名采集，也不得生成产品 Issue。

## 实施前置条件

正式开发前仍需单独确认威胁模型、数据保留时长、删除入口、部署环境隔离能力和可接受站点清单，并补充凭据不落盘、跨域阻断、会话销毁、审计脱敏和人工停止的自动化测试。未满足这些条件前，README 和 UI 必须继续标记为“未实现”。
