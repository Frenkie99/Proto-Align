# ProtoAlign 参考图视觉原则 V2

## 视觉定位

明亮、柔和、带轻微未来感的高级工作台。不是传统灰白后台，也不是蓝紫霓虹 AI 页面。整体像被自然环境光照亮的半透明工作桌：背景克制、关键对象清楚、少量跳色足够醒目。

## 从五张参考图提炼出的共同语言

1. **高亮环境光而非装饰渐变。** 渐变放在应用背景、顶部时间线或选中区域周围，形成青蓝、薄荷、淡黄的光晕；内容本身仍保持可读的浅色表面。
2. **黑色是视觉锚点。** 黑色胶囊按钮、当前导航、关键操作和少量深色区域稳定画面，避免页面因浅色与玻璃效果而发飘。
3. **跳色集中在少数任务对象。** 荧光黄绿、青蓝、珊瑚红、柔紫只用于当前问题、状态、来源和原型标注，不平均撒在每张卡片上。
4. **融合式分区。** 左、中、右可以共享同一个浅色环境；通过稳定列宽、连续分隔线、独立标题栏、容器边缘、留白和信息密度形成工作区，不靠三块不同底色生硬切割。
5. **大圆角但形态不平均。** 使用 16–28px 的圆角，搭配胶囊控件和圆形按钮；卡片尺寸与占比不对称，避免一排相同方块的模板感。
6. **毛玻璃只用在浮层。** 顶部工具条、Agent 浮层、下拉和悬浮操作可使用透明背景与 blur；主要阅读区保持足够实，保证中文信息密度下的清晰度。
7. **轻字重与大尺度层级。** 页面标题舒展，正文细而清楚，元信息弱化；不依赖到处加粗制造层级。
8. **微弱边界与柔和阴影并用。** 常驻模块使用半透明白边和低浓度阴影；真正的列边界仍保留一条连续细线，不能完全靠阴影猜测区域。
9. **真实任务替代装饰数据。** 不引入评分、百分比、趋势图和统计数字。参考图中的数据模块语言转译为问题、证据、版本、验证条件和人的决定。

## 语义色映射

- 阻塞交付：珊瑚红 / 淡红表面。
- 待确认：荧光黄绿或琥珀黄 / 高亮但不表示已完成。
- 处理中：清亮钴蓝 / 淡蓝表面。
- AI 推断·待确认：柔紫 / 淡紫表面。
- 客户反馈：暖橙标签。
- 研发反馈：蓝色标签。
- 已核验：薄荷绿。

## 三个方案

### A. 柔光精修版
保留用户已经认可的三栏结构和阅读顺序。用环境光、玻璃顶栏、语义跳色问题卡、柔和圆角和更精致的 Agent 检查器提高完成度。

### B. 聚焦画布版
中间原型是最大的白色舞台；左侧问题压缩为轻量彩色队列，右侧 Agent 变成悬浮检查器。证据作为画布底部抽屉，强调“定位原型并解决一个问题”。

### C. 模块工作台版
采用非对称 Bento 栅格，但每个模块都服务真实任务：问题队列、原型定位、证据、Agent 判断、验证条件和决策。避免分析图表与虚构指标。
