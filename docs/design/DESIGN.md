# ProtoAlign 基础设计规范

## 设计立场

ProtoAlign 是面向初阶 AI 产品经理的项目级问题闭环 Agent。界面必须像一张可工作的调查桌：结论克制、证据可回溯、人的决策权清楚。它不扮演“万能 AI 老师”，也不把风险包装成漂亮分数。视觉上的可信度来自可验证的信息关系，而非发光、渐变、夸张圆角或虚构指标。

## 反模板化原则

1. **结构先于皮肤。** 三种设计方向必须改变用户从哪里进入任务、如何推进任务、怎样理解 Agent 的工作，而不是只替换颜色、字体、阴影或圆角。
2. **问题不是卡片库存。** Issue 必须和原型位置、来源证据、当前决定、验证条件同时出现；禁止用一排同质卡片把复杂关系压成摘要。
3. **Agent 不等于聊天框。** Agent 的可见工作应表现为检索、对照、生成草稿、等待确认等可验证活动；对话只承担解释与辅导，结构化控件承担状态改变。
4. **不用总分制造确定性。** 交付判断使用“暂不可交付 / 需确认 / 可进入研发评审”等门槛语言，并列出阻塞原因；不展示来源不明的 78 分、完成率或趋势图。
5. **证据永远贴近判断。** 关键结论旁必须能看到来源角色、资料名称、时间或版本。AI 推断必须明确标注“待确认”。
6. **只保留一个有彩色强调。** 强调色用于阻塞、选中、可执行动作与原型标注，其余状态通过明度、线型、字重和空间层级表达。
7. **边界替代悬浮卡。** 优先使用规则线、分栏、底色变化和留白组织信息；卡片只在内容确实是可独立操作对象时出现。
8. **中文排版是产品质量的一部分。** 正文控制在 14–16px、1.55–1.75 行高；标题不滥用英文 display 字体；中西混排采用 Geist / IBM Plex Sans + 苹方 / 思源黑体回退；禁止伪斜体。
9. **状态变化可解释。** 任何关闭、延后、重新打开或标记待验证的操作，都需要在界面中说明依据和下一步，而不是只弹一个“成功”提示。
10. **动效只解释因果。** 允许问题定位、证据展开、Agent 活动更新、版本切换使用 160–260ms 的位移或淡入；禁止无意义呼吸光、粒子、漂浮装饰和持续旋转。

## 视觉语法

- **底色：** 暖灰纸白 `#F3F1EC` 或中性近白 `#F7F7F5`，深色方向使用中性炭黑 `#151515`，避免蓝黑 GitHub 风。
- **文字：** 主文字 `#171715`，次级文字 `#6B6962`，弱化线 `#D6D2C8`；深色反向使用 `#F2F0EA / #AAA69D / #34322E`。
- **唯一强调色：** 氧化朱红 `#C24F35`。它来自“评审批注与修订痕迹”的文化语义，降低饱和度后保留警示与编辑感，不像通用科技蓝。
- **字体：** `Geist, "IBM Plex Sans", "PingFang SC", "Noto Sans SC", sans-serif`；编号、版本、来源标签使用 `Geist Mono, "IBM Plex Mono", monospace`。不使用 Inter 作为大标题。
- **字号：** 页面标题 24–32px；区块标题 16–18px；正文 14–16px；元信息 11–12px。最多五档。
- **圆角：** 0 / 4 / 8px 三档。关键工作区与列表用直角或 4px；浮层与对话输入可用 8px。禁止 20px 以上软糖圆角。
- **线与阴影：** 1px 规则线为主；阴影仅用于浮层 `0 12px 36px rgba(20,18,14,.12)`，常驻内容不堆阴影。
- **按钮：** 主按钮使用实心朱红或深色；次按钮用描边；危险关闭动作不能只靠红色区分，必须配文字。
- **焦点与可达性：** 所有可点击元素提供 hover、focus-visible 和 active 状态；强调色与背景保证正文级对比；不依赖颜色单独表达来源或状态。

## 组件约束

- 问题条目至少显示：标题、来源、状态、关联页面/版本；AI 问题必须显示“AI 推断·待确认”。
- 问题详情至少显示：影响、证据、建议、确认对象、验证条件、当前决定。
- 原型视图必须支持版本下拉，而非只放 V1/V2 两个按钮。
- Agent 活动只显示行动摘要与工具结果，不展示隐含思维链；例如“已对照客户纪要与研发约束，发现一处冲突”。
- 结构化动作包括：开始处理、发起澄清、延后、接受风险、标记待验证、关闭问题。
- 对话建议用短问句引导产品经理确认事实和取舍，避免连续长篇教学。

## 三个方向的共同底线

- 固定画布为 1440×1024 的桌面高保真演示，并提供合理的窄屏降级。
- 使用同一个“AI 客服回复助手”项目、同一组问题与证据，便于比较设计思路本身。
- 不使用 Lorem Ipsum、无来源统计数字、品牌 Logo、emoji 或装饰性 AI 星光图标。
- 至少实现版本切换、问题选择/步骤切换、Agent 信息展开或结构化动作中的两类交互。
