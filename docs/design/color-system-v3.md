# ProtoAlign V3 固定色系规范

## 共同规则

- 页面只允许一个有彩色系，加黑、白、灰中性色。
- 渐变只用于应用最外层环境背景；卡片、面板、按钮和状态标签使用纯色或单色透明度变化。
- 业务状态通过同色系的明度、饱和度、填充/描边方式和文字标签表达，不为每个状态引入新色相。
- 完整保留问题队列、问题上下文画布、关联证据、Agent 解读、重要性、确认问题、验证条件、下一步、对话和结构化操作。

## 方案一：冰川蓝白＋黑

- 环境：白色到浅冰蓝的单向渐变。
- 主色：清透青蓝与钴蓝。
- 锚点：近黑导航、黑色胶囊按钮和深色关键操作。
- 状态：阻塞使用黑色实底；待确认使用蓝色描边；处理中使用青蓝实底。
- 参考：用户指定的蓝白 HR Dashboard。

## 方案二：青柠黄绿＋黑

- 环境：暖白到极浅鼠尾草绿的单向渐变。
- 主色：青柠黄与苔绿色。
- 锚点：墨绿色近黑。
- 状态：阻塞使用墨绿近黑；待确认使用青柠描边/浅底；处理中使用苔绿色。

## 方案三：雾紫＋深紫

- 环境：冷白到浅雾紫的单向渐变。
- 主色：薰衣草紫与深紫。
- 锚点：深紫黑。
- 状态：阻塞使用深紫黑；待确认使用浅紫描边；处理中使用中等紫色。
